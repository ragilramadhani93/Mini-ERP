* **MEDIUM (Purpose-Gate):** 2 temuan (menunggu konfirmasi user).
* **LOW (Quality Locks):** 3 temuan (menunggu konfirmasi user).

## Daftar Temuan Bernomor (Numbered Findings)

### [HIGH Priority - Hard Gate Violations]

#### 01. Broken Navigation Link pada Sub-Menu Sidebar (R-24 & R-26)
* **File:** [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js#L44) & [router.js](file:///d:/Online%20Seller/apps/web/src/utils/router.js#L9)
* **Alasan:** Sub-menu "Stok Rendah" mengarah ke `/products?filter=low-stock`, tetapi router mencocokkan string path persis (`this.routes[path]`). Karena rute tersebut tidak terdaftar di `app.js`, router langsung fallback ke `/` (Dashboard). Pengguna yang mengklik "Stok Rendah" terlempar ke Dashboard.
* **Rekomendasi:** Perbaiki router agar mendukung query params atau sesuaikan navigasi ke rute produk dengan filter event internal.

#### 02. Dead Search Input di Header Utama (R-26)
* **File:** [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js#L264)
* **Alasan:** Input pencarian `"Cari data..."` di bar navigasi atas di-render statis tanpa `id` spesifik dan tanpa `event listener` apa pun. Mengetik di kolom ini tidak memberikan aksi atau hasil apa pun.
* **Rekomendasi:** Berikan `id="global-search"`, pasang logic pencarian global atau hapus elemen jika fitur pencarian global belum diimplementasikan.

#### 03. Dead Interactive Notification & Profile Avatar di Header (R-26 & R-32)
* **File:** [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js#L272-L278)
* **Alasan:** Tombol lonceng (dengan dot merah notifikasi) dan avatar inisial pengguna memiliki styling `cursor:pointer`, namun tidak memiliki event click, tidak membuka menu/dropdown notifikasi, serta tidak memiliki label aksesibilitas (`aria-label`).
* **Rekomendasi:** Hubungkan tombol ke modal/popover notifikasi dan menu profil, atau nonaktifkan status interaktifnya.

#### 04. Dead Filter Dropdowns pada Halaman Produk (R-26)
* **File:** [ProductsPage.js](file:///d:/Online%20Seller/apps/web/src/pages/ProductsPage.js#L98-L106)
* **Alasan:** Dropdown `<select id="category-filter">`, `<select id="supplier-filter">`, dan `<select id="stock-filter">` ditampilkan di UI, namun di `_bindListeners()` tidak ada satu pun event listener yang menangani perubahannya. Memilih opsi filter tidak berdampak pada tabel.
* **Rekomendasi:** Tambahkan event listener `change` pada ketiga select tersebut dan filter data produk di memori/query.

#### 05. Dead Action Button "Export Data" Menggunakan Browser Alert (R-26)
* **File:** [ProductsPage.js](file:///d:/Online%20Seller/apps/web/src/pages/ProductsPage.js#L173)
* **Alasan:** Tombol `#export-btn` hanya menjalankan `alert('Export feature coming soon!')`. Menampilkan kontrol yang belum bekerja melanggar R-26.
* **Rekomendasi:** Integrasikan dengan utilitas `Exporter.exportProducts()` yang sudah ada di codebase atau hilangkan tombol dari tampilan utama.

#### 06. Aksi Palsu pada Barcode Scanner (R-26)
* **File:** [BarcodePage.js](file:///d:/Online%20Seller/apps/web/src/pages/BarcodePage.js#L166)
* **Alasan:** Tombol aksi "Penjualan" (`action-sale`) setelah scan produk tidak memasukkan produk ke transaksi kasir, melainkan hanya berpindah ke `/sales` lalu menampilkan `alert` menyuruh pengguna memasukkan produk sendiri secara manual.
* **Rekomendasi:** Simpan item yang di-scan ke state transaksi atau localStorage, lalu arahkan ke SalesPage dengan keranjang belanja yang otomatis terisi.

#### 07. Seluruh Modal Dialog Tidak Bisa Ditutup dengan Tombol Keyboard Escape (R-32)
* **File:** `SalesPage.js`, `StockPage.js`, `FinancePage.js`, `ProductsPage.js`, `DepositPage.js`, `ReturPage.js`, `DebtPage.js`, `PurchaseOrderPage.js`, `SettingsPage.js`, `UsersPage.js`, `CategoriesPage.js`, `SuppliersPage.js`, `AssetsPage.js`
* **Alasan:** Semua modal hanya mengandalkan klik tombol silang atau overlay click. Tidak ada penanganan event `keydown (Escape)`, melanggar standar aksesibilitas keyboard wajib (R-32).
* **Rekomendasi:** Tambahkan helper universal penutup modal saat event `e.key === 'Escape'` ditekan.

#### 08. Penggunaan Browser Popups (Prompt / Confirm / Alert) yang Merusak UX (R-32 & Craftsmanship C-4)
* **File:** [DebtPage.js](file:///d:/Online%20Seller/apps/web/src/pages/DebtPage.js#L72), [StockPage.js](file:///d:/Online%20Seller/apps/web/src/pages/StockPage.js#L85), [ReturPage.js](file:///d:/Online%20Seller/apps/web/src/pages/ReturPage.js#L290), [StockOpnamePage.js](file:///d:/Online%20Seller/apps/web/src/pages/StockOpnamePage.js#L175)
* **Alasan:** Input pembayaran hutang menggunakan `prompt()` teks browser. Konfirmasi hapus dan input massal menggunakan `confirm()`. Validasi menggunakan `alert()`. Dialog native ini memblokir rendering browser, merusak pengalaman di layar sentuh/mobile, dan tidak ramah pembaca layar.
* **Rekomendasi:** Ganti dengan modal konfirmasi dan form dialog in-app yang konsisten.

#### 09. Hilangnya Indikator Fokus Keyboard pada Search Input (`outline:none`) (R-32)
* **File:** [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js#L264)
* **Alasan:** Menggunakan inline style `outline:none` tanpa adanya custom focus ring atau border highlight ketika input dipilih via navigasi keyboard (Tab).
* **Rekomendasi:** Terapkan focus ring yang jelas (misal Tailwind `focus:ring-2 focus:ring-primary-500 focus:outline-none`).

#### 10. Kontras Warna Buruk pada Empty States & Badges (R-25)
* **File:** `DashboardPage.js`, `FinancePage.js`, `ProductsPage.js`, `StockPage.js`, `AnalyticsPage.js`
* **Alasan:** Teks pesan kosong (`color:#9ca3af` / `text-gray-400`) di atas latar putih atau abu-abu (`#f8fafc`) memiliki rasio kontras ~2.1:1, gagal memenuhi syarat WCAG AA minimum 4.5:1. Hal serupa terjadi pada label warning (`#f59e0b` di atas `#fffbeb`).
* **Rekomendasi:** Tingkatkan kegelapan warna teks sekunder minimal ke `text-gray-600` (#4b5563) atau `#64748b` agar kontras mencapai > 4.5:1.

#### 11. Silent Error Handling pada Dashboard (R-27 & Craftsmanship C-4)
* **File:** [DashboardPage.js](file:///d:/Online%20Seller/apps/web/src/pages/DashboardPage.js#L48-L52)
* **Alasan:** Jika Supabase gagal mengambil data atau jaringan terputus, `catch (error)` hanya mengosongkan state tanpa menampilkan notifikasi/tampilan error state ke user. Dashboard tetap tampil dengan omset Rp 0 seolah-olah toko tidak memiliki aktivitas.
* **Rekomendasi:** Sediakan tampilan Error State dengan tombol "Coba Lagi" saat pengambilan data gagal.

#### 12. Tap Target Interaktif di Bawah 44px untuk Mobile (R-03)
* **File:** [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js#L272) (Header actions 34px), [ProductsPage.js](file:///d:/Online%20Seller/apps/web/src/pages/ProductsPage.js#L130) (Tombol aksi tabel), [ReturPage.js](file:///d:/Online%20Seller/apps/web/src/pages/ReturPage.js#L140)
* **Alasan:** Tombol-tombol aksi kecil (misal tombol edit, hapus, dan header button) memiliki tinggi/lebar fisik hanya 28px s/d 34px, melanggar batas minimum ukuran tap target sentuh 44px.
* **Rekomendasi:** Berikan padding area sentuh minimal `min-h-[44px] min-w-[44px]` atau bungkus dalam container tap target yang memadai.

#### 13. Data Palsu / Stat Arbitrer pada AI Forecast & Target Omset (R-17 & R-36)
* **File:** [DashboardPage.js](file:///d:/Online%20Seller/apps/web/src/pages/DashboardPage.js#L80-L82), [DashboardPage.js](file:///d:/Online%20Seller/apps/web/src/pages/DashboardPage.js#L207-L220)
* **Alasan:** Kode mematok angka statis `cuanTarget = 500000` tanpa opsi pengaturan toko, dan section "AI Forecast" menampilkan persentase statis hardcode `+ 12%` tanpa model kalkulasi nyata.
* **Rekomendasi:** Jadikan target omset dapat dikonfigurasi melalui Settings, atau gunakan data rata-rata historis nyata dan hapus klaim statistik palsu.

#### 14. Penggunaan Endpoint AI Eksternal untuk Avatar Placeholder (R-23)
* **File:** [ProfilePage.js](file:///d:/Online%20Seller/apps/web/src/pages/ProfilePage.js#L54) & [RegisterPage.js](file:///d:/Online%20Seller/apps/web/src/pages/RegisterPage.js#L12)
* **Alasan:** `ProfilePage` menggunakan fallback URL ke generator AI eksternal `trae.ai` dengan prompt teks alih-alih placeholder inisial SVG lokal. Di `RegisterPage`, gambar logo memiliki nama file mentah `ChatGPT Image Jun 21...`.
* **Rekomendasi:** Ganti avatar fallback dengan inisial nama berbasis SVG lokal murni tanpa ketergantungan API pihak ketiga, dan rapikan aset logo.

#### 15. Ketidaksinkronan Matriks Perizinan Role (R-24 & R-26)
* **File:** [SettingsRolePage.js](file:///d:/Online%20Seller/apps/web/src/pages/SettingsRolePage.js#L10) & [ProfilePage.js](file:///d:/Online%20Seller/apps/web/src/pages/ProfilePage.js#L12)
* **Alasan:** Halaman baru `/deposits` (Deposit) dan `/returns` (Retur) sudah aktif di navigasi [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js), namun belum terdaftar di array `menuItems` pengaturan peran. Owner tidak dapat mengatur izin hak akses kedua halaman tersebut untuk staf.
* **Rekomendasi:** Daftarkan menu `/deposits` dan `/returns` ke daftar `menuItems` di kedua file tersebut.

### [LOW Priority - Quality Locks Violations]

#### 18. Tabrakan Palet Warna Brand (Burgundy vs Indigo) (R-20 & R-29)
* **File:** [Layout.js](file:///d:/Online%20Seller/apps/web/src/components/Layout.js), [SettingsPage.js](file:///d:/Online%20Seller/apps/web/src/pages/SettingsPage.js), [FinancePage.js](file:///d:/Online%20Seller/apps/web/src/pages/FinancePage.js), [global.css](file:///d:/Online%20Seller/apps/web/src/styles/global.css)
* **Alasan:** Aplikasi memiliki dua warna primer yang bertabrakan: warna tema Tailwind `primary-600` (indigo/biru) dan warna hardcoded inline `#7A3B58` (burgundy/maroon) yang digunakan acak di tab, badge, dan logo.
* **Rekomendasi:** Satukan tema ke dalam variabel CSS / Tailwind config yang tunggal sehingga semua tombol dan status pill konsisten.

#### 19. Karakter Unicode Rusak (Corrupted Encoding) di Berbagai Halaman (R-02 & Craftsmanship C-1)
* **File:** `DashboardPage.js`, `DepositPage.js`, `AIAssistantPage.js`, `DebtPage.js`, `ForecastingPage.js`, `BarcodePage.js`, `PurchaseOrderPage.js`
* **Alasan:** Banyak teks menampilkan karakter rusak seperti `dY`<<`, `?`, `s,?`, `^z`, dan `dY"`. Ini terjadi akibat penyimpanan file sebelumnya dengan encoding UTF-8/ANSI yang tidak tepat.
* **Rekomendasi:** Bersihkan seluruh string yang rusak dan ganti dengan teks bahasa Indonesia baku atau ikon Lucide resmi.

#### 20. Dummy Pelanggan Hardcoded pada Form Transaksi Penjualan (R-17 & Quality)
* **File:** [SalesPage.js](file:///d:/Online%20Seller/apps/web/src/pages/SalesPage.js#L35-L43)
* **Alasan:** Dropdown nama pelanggan pada form penjualan menggunakan array statis hardcoded dummy (`Rumah Tangga Bahagia`, `Toko Elektronik Jaya`, dsb.) alih-alih riwayat transaksi pelanggan atau input teks dinamis.
* **Rekomendasi:** Ganti dengan input teks auto-suggest atau ambil data pelanggan unik dari database riil.
